# Reboot · 12 месяцев

Личное focus-приложение под план 2026-05-23 → 2027-05-23: «Из найма в продукт через Бали».

Один экран — один следующий шаг. Никаких сказок про прогресс — только цифры.

## Что внутри

- **Сегодня** — прогресс года, самый горящий шаг, просроченные и ближайшие 14 дней, быстрые метрики.
- **План** — все шаги S1–S5 и параллельные треки (похудение, английский) с чекбоксами, прогрессом и дедлайнами.
- **Отчёт за день** — фокус, энергия, что сделано, что блокирует, топ-приоритет завтра + трекинг (постов, тренировок, английского, веса, outbound).
- **Рефлексия** — еженедельный шаблон по воскресеньям 19:00.
- **Инсайты** — быстрый capture с тегами, поиск, важное.
- **Метрики** — KGI, график веса vs целевая кривая, 30-дневный heatmap привычек, экспорт/импорт JSON.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

## Деплой

Push в GitHub → подключить репозиторий на vercel.com → готово. Никаких env vars не требуется для базовой работы.

### Опционально: Supabase

Без него всё работает на `localStorage` и переживает обновления страницы.

Чтобы синхронизировать между устройствами, добавь в Vercel переменные:

```
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
```

(Слой синхронизации добавим, когда будет нужно — пока локального хранения достаточно для одного пользователя.)

## Структура

- `app/` — страницы (App Router)
- `components/Nav.tsx` — нижняя навигация
- `lib/plan-data.ts` — план в виде TS (единый источник истины)
- `lib/store.ts` — localStorage-хранилище и хуки
- `lib/date.ts` — утилиты
